POTENTIAL RISKS:
- Performance: 8.5MB renderdoc DLL = ~2152 stealth pages. Each code instruction
  causes 2+ VM exits (NX-fetch + MTF). ept_update_pf_intercept walks 2152
  entries on every MTF. System may appear SLOW but should not crash.
- NMI during vmx_enter_cr3 window: private IDT handler halts CPU (safety).
  Unlikely to occur in practice.
