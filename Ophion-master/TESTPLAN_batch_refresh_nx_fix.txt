TESTPLAN: batch refresh NX inversion fix
Date: 2026-08-09

BUG: stealth_batch_refresh_shadow_ptes zeroed ALL NX=1 shadow PTEs.
     After IOCTL_SHADOW_PROTECT_MEMORY, renderdoc code pages have NX=1 in real PT
     (stealth) but P=1/NX=0 in shadow PT (executable). Batch refresh overwrote
     these to P=0 -> fault_spte check failed -> #PF re-injected -> AV crash.

FIX: batch refresh now preserves existing shadow PTE policy:
     - real P=0 -> shadow P=0 (page freed)
     - shadow P=0 -> keep P=0 (data page, reactive sync)
     - shadow P=1 -> (rp & ~NX_BIT) | (sp_old & NX_BIT) (refresh PFN, keep NX policy)
